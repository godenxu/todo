# 科技规划处任务管理系统

一个**零依赖、单文件**的任务/项目管理工具。整个应用就是一个 `index.html`，用浏览器打开即可使用，无需服务器、无需安装；可仅本机使用，也可通过局域网共享文件夹实现多人协同。

按照「**职责 → 工作 → 任务 → 里程碑**」四级体系组织工作，覆盖从年度职责规划到具体交付物跟踪的全过程，并内置身份识别、角色权限、图表看板、周期简报等管理能力。

## ✨ 特性一览

- **单文件即用**：双击 `index.html` 用浏览器（推荐 Chrome / Edge / 360 极速模式等 Chromium 内核）打开就能用。
- **四级数据模型**：职责（年度大类）→ 工作（具体项目）→ 任务（可分工的执行项）→ 里程碑/交付物（带计划日期、完成状态、最高呈报层级）。
- **身份与权限**：PIN 登录识别使用者，五级角色（员工/组长/处室领导/部门领导/管理员）配合可配置的权限矩阵，控制查看、编辑、批量操作、账号管理等权限点。
- **多人协同（可选）**：管理员可配置一个局域网共享文件夹，各账号按工号自动对应各自应连接的路径；连接后任务/工作/职责/里程碑数据按"版本号 + 更新时间"逐条合并同步，每 5 分钟自动刷新一次，无需服务器。
- **快捷输入**：任务页顶部一行话录入任务，支持所属工作、参与人、优先级、计划完成日期的简写语法。
- **表格化管理**：任务/工作/职责均为可排序、可拖拽列宽的表格，支持行内双击编辑；大列表采用虚拟滚动，数千条数据也流畅。
- **多维筛选**：任务页、工作页左侧栏均可按状态、人员、所属职责/工作等条件筛选，并实时显示各分类数量。
- **里程碑/检查点管理**：任务详情弹窗内联编辑里程碑（交付物+计划日期+最高呈报层级），支持拖拽排序，任务进度按里程碑完成比例自动计算。
- **工作台**：需要关注（逾期/今日到期/本周到期/未指派）、任务与里程碑双维度统计卡片、各职责/工作推进情况、里程碑甘特图（默认聚焦"我的里程碑"）、我的工作台、人员负荷、最近动态。
- **图表页**（六个维度）：按人 / 按任务 / 按工作 / 按职责 / 按时间 / 按里程碑，每张图都可切换"看图表 / 看数据表"。
  - 按时间：待办任务总量趋势（月/周/日粒度可切换，看待办是在堆积还是在消化）、未完成任务到期分布、从本月起各月计划完成的任务数与里程碑数。
  - 按里程碑：里程碑完成情况分布、交付物呈报层级分布、职责→工作→任务逐级展开的里程碑甘特图。
- **报告页**：按本周/本月/本季/本年一键生成简报（总览大卡片 + 各职责/工作推进情况），支持导出为图片。
- **软删除 + 撤销**：删除进入"已删除"视图可恢复或彻底删除；新建、编辑、状态变更、删除、批量导入等操作均可撤销。
- **CSV / 宽表导入导出**：任务、工作、职责可分别导出；支持"任务+里程碑"宽表一体化导入（覆盖或增量两种模式）。
- **数据体检**：一键检测孤儿任务/里程碑、编号重复、缺计划完成时间、里程碑日期晚于任务计划完成时间等问题，部分问题可一键修复。
- **年度复制**：按年度批量复制职责/工作结构，快速开启下一年度的规划。

## 🚀 快速开始

1. 下载仓库中的 `index.html`。
2. 双击用浏览器打开。
3. 首次打开会引导创建第一个账号（自动成为管理员），之后每次打开都会要求选择/验证身份（PIN）。
4. 系统首次使用时会生成一批示例数据，正式使用前可到「数据」页一键清除标记为"测试"的数据。

## 🗂️ 数据模型

```
职责（年度大类，如"一、前瞻研判"）
 └─ 工作（具体项目/事项，有牵头人、参与人、状态）
     └─ 任务（可分工的执行项，有牵头人、参与人、优先级、状态、计划完成时间）
         └─ 里程碑 / 交付物（计划日期、完成状态、最高呈报层级：处室领导/部门领导/行领导）
```

任务的进度由其名下里程碑的完成比例自动计算；里程碑列表支持拖拽调整顺序。

## 📄 页面导览

| 页面 | 说明 |
|------|------|
| **工作台** | 首页概览：需要关注的任务、任务/里程碑双维度统计卡片、各职责/工作推进情况、里程碑甘特图（可切换"我的里程碑"）、我的工作台、人员负荷、最近动态 |
| **任务** | 任务表格，支持全部任务/我的任务/逾期/今日到期/本周/进行中等多种预设视图，行内编辑，批量操作 |
| **工作** | 工作表格，按职责组织，可下钻查看所属任务 |
| **职责** | 职责列表与年度管理 |
| **图表** | 按人/按任务/按工作/按职责/按时间/按里程碑六个维度的统计图表 |
| **报告** | 按周期（本周/本月/本季/本年）生成的可读简报，支持导出图片 |
| **数据** | CSV/宽表导入导出、共享文件夹连接与配置、数据体检、年度复制、测试数据清理（管理员可见范围更全） |
| **权限** | 角色与权限矩阵配置、账号管理（仅管理员可见） |

## 👤 身份与权限

- 首次使用需创建账号并设置 PIN（PBKDF2 哈希存储，不落明文）；之后每次打开都要选择本人身份并验证 PIN。
- 五级角色：**员工 / 组长 / 处室领导 / 部门领导 / 管理员**，角色挂在账号上（随共享文件同步），不是本机可随意更改的设置。
- 管理员可在「权限」页配置一张角色 × 权限点的矩阵，控制：各页面查看权限、是否可查看他人任务详情、是否可编辑他人负责的任务/工作、职责与工作的增删改、批量操作（CSV 导入、年度复制、数据体检修复等）、账号与角色管理、共享文件连接等系统级操作。

## 🔗 多人协同（共享文件同步）

- 管理员可在「数据」页配置一个共享文件夹的路径模板（用 `{工号}` 占位），系统按每个账号的工号自动算出其应连接的路径，避免大家各自乱选文件夹。
- 连接后，职责/工作/任务/里程碑/变更日志会与共享文件夹里的 JSON 文件同步；每次保存都按"版本号 + 更新时间"逐条合并，不会整体覆盖。
- 页面每 5 分钟自动与共享文件同步一次（不刷新整页，编辑中或有弹窗时会跳过）。
- 使用者身份、列宽等个人设置只留在本机，不参与同步。
- 需要 Chrome / Edge / 360 极速模式等支持 File System Access API 的 Chromium 内核浏览器，Firefox 等不支持。

## ⌨️ 快捷输入语法

在任务页顶部的快速输入框中，用空格分隔的标记可以一次性设置任务属性：

| 语法 | 含义 | 示例 |
|------|------|------|
| `$工作编号或名称` | 关联所属工作 | `$0102` 或 `$合规审查` |
| `@人员` | 添加参与人（可多个） | `@张三 @李四` |
| `~日期` 或裸日期 | 计划完成时间 | `~fri`、`+3`、`2026-06-30` |
| `!1` `!2` `!3` | 优先级（1 高 / 2 中 / 3 低） | `!1` |
| 其余文字 | 作为任务标题 | |

**日期写法**支持：`today`、`tomorrow`、`+3` 或 `+3d`（N 天后）、`mon`/`tue`/…/`sun`（本周或下周最近的星期几）、`next-mon`（下周一）、`2026-06-30`（指定日期）。

示例：

```
整理季度合规报告 $0102 @张三 @李四 !1 fri
```

> 创建一个标题为「整理季度合规报告」、关联工作编号 0102、参与人张三和李四、优先级高、本周五计划完成的任务。

## 📥 导入导出与数据体检

- 任务、工作、职责均可各自导出为 CSV（UTF-8 带 BOM，Excel 可直接打开）。
- 支持"任务 + 里程碑"宽表一体化导入：**覆盖模式**按任务编号匹配并整体替换（含其下全部里程碑），**增量模式**全部作为新任务导入；可先下载模板核对列名。
- 「数据」页的**数据体检**可一键发现：孤儿任务/里程碑、职责或工作编号重复、未完成任务缺计划完成时间、里程碑计划日期晚于任务计划完成时间等问题，部分问题支持一键修复。

## 💾 数据与存储

- 数据默认保存在浏览器本地 **localStorage**（键名 `todo_v4`），仅存于本机；清理浏览器数据会导致数据丢失，请通过共享文件同步或定期导出 CSV 备份。
- 若已连接共享文件夹，数据会额外持久化到该 JSON 文件中，作为多设备/多人之间的同步载体。
- 页面左下角会显示当前构建版本号，便于确认各终端是否为同一版本。

## 🧪 测试

`test/` 目录下是一套基于 Node `vm` 沙盒的回归测试（`test-p2.js` … `test-pN.js`），直接对 `index.html` 里的纯逻辑函数做断言，不依赖浏览器：

```bash
node test/test-p2.js
```

每个文件对应某一批功能的专项回归，新增功能时通常会同步补充对应的测试文件。

## 🛠️ 技术栈

- 原生 **HTML + CSS + JavaScript**，无任何框架或第三方库，全部逻辑、样式、结构内联于单个 HTML 文件中。
- 多人同步基于浏览器原生 **File System Access API**，无需后端服务。
- 身份校验使用浏览器原生 **Web Crypto（PBKDF2）** 做 PIN 哈希。
